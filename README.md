# MicrobioDash
The tool's customizable interface and AI-assisted workflow make it accessible to researchers with different levels of expertise, improving microbiome analysis in ecological, medical, and agricultural fields.


# Microbiome Analysis Dashboard

## Overview
This project is a Dash-based web application for microbiome analysis that incorporates AI for parameter optimization and generates reports. It leverages various libraries for statistical analysis, visualization, and data processing.

## Requirements
To run this application, you need the following Python packages:

- dash
- plotly
- skbio
- pandas
- numpy
- biopython
- scipy
- statsmodels
- ete3
- google.generativeai
- reportlab
- matplotlib
- seaborn

You can install the required packages using pip:

```bash
pip install dash plotly skbio pandas numpy biopython scipy statsmodels ete3 google-generativeai reportlab matplotlib seaborn
